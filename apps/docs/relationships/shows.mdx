---
title: "Shows"
description: "Book shows, build the set and send the DJ the tracks."
---

Go to **Relationships** > **Shows**.

## Book a show

1. Tap **Book a show**.
2. Choose **One show** or **Festival**.
3. Pick the artist, name the show, and add the set start, set length, venue and city.
4. Tap **Book show**.

Set times always show on the venue's clock. No time yet? The show reads "Date to confirm".

You can also add a show from an artist's page. Tap **Add a show** in their Shows section.

## Build the set

Open the show and add songs to the set. For each song you can add the length, BPM, key, a note for the DJ and the file the DJ should play. Move songs up or down to change the order.

## Run of show

Under **Run of show**, add steps like soundcheck, with a time and a day (day before, show day or day after).

## Send the tracks

Under **Send the tracks**, add the DJ and anyone else who needs the files. Each person gets their own private link, so you can see who has the songs. Tap **Copy link** or **Send on WhatsApp**. **Turn off link** stops a link straight away.

## Create it

<Steps>
  <Step title="Open Rollouts">
    Go to **Catalogue** > **Rollouts** and tap **Add rollout**.
  </Step>
  <Step title="Name it">
    Type the song or project title. This is optional. Leave it empty and it is called "Untitled rollout" until you name it.
  </Step>
  <Step title="Pick the format">
    Choose **Single**, **EP** or **Album**, then tap **Create rollout**.
  </Step>
  <Step title="Answer the planner">
    The AI planner opens. Answer its questions and tap **Build my plan**. See [The plan](/releases/playbook).
  </Step>
</Steps>

<Tip>
  You can also ask AI: "Plan a rollout for my new single." It asks the same questions in the chat.
</Tip>

## Rather plan it yourself?

Close the planner. On the rollout, tap **Add an activity yourself** and build the list by hand.

## Plan limits

Each plan has a limit on how many rollouts you can work on at once:

| Plan | Rollouts at a time |
| - | - |
| Solo | 1 |
| Manager | 3 |
| Label | Unlimited |

Released and archived rollouts do not count. See [Plans and prices](/account/subscription).

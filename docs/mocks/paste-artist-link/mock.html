Which links work

  • Apple Music and Deezer artist links: yes, from day one. Urganize already reads both. That is where the search looks today.
  • Spotify: not yet. The code to read Spotify is there, but the Spotify keys are not set on the live app (checked 8 Nov). They come from a free Spotify developer account. Once they are added, a Spotify link works too and the help line names Spotify first. Until then a Spotify link gets the "can't read" message. Adding the keys is a separate yes.
  • Audiomack, Boomplay, YouTube and others: no. Their songs can't be brought in, so we say which links to use instead.

What stays the same

  • The check screen, the "Is this the same person?" question when someone on the roster has a close name, and "Add by name".
  • The Home popup's guess. Pasting a link is only for when the guess and the search both miss.

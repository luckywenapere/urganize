One flow: from the song to the review

You open a project for a song and the checklist is there. Pick a release day and the same project becomes the rollout. After release, a review feeds the next song. Built from the app’s shadcn components, with a cleaner look than today’s app. Names and numbers are made up.

Lessons go in
One page, three stages
Song, Release and Out sit on one project page. The tasks change with the stage. You never jump to another page.
The checklist is there from the start
Open a project and the full list is already there, in order. No “suggested” tasks to add one by one.
No dates until a release day
Making a song doesn’t run to a deadline. Dates appear when you pick a day.
The review closes the loop
Fans, team and streams in one page, by email too. Three lessons go into the next song’s plan.
What’s better than today’s UI
Stage track instead of three boxes
One line with three points. You see where you are and how far there is to go at a glance.
Groups that fold
Finished groups shrink to one line with a tick, so the screen shows only what’s left.
One action at the bottom
The main button sits in a fixed bar at the bottom, in thumb reach, on every screen.
Colour means something
Green is done or today, amber is late. People get their own colour. Less beige, more contrast.
Cover art on every song
A square per song, so lists are quick to scan. Before there’s art it uses the song’s colour.
Fewer fonts
The serif only for page titles. Mono capitals are gone. Everything else is one clean sans.

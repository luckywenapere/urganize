Questions I'd settle before building
  • How long it stays: I'd keep it 7 days from release day, then it goes. A link is still worth sharing in the first week.
  • "Not now": a small "Hide" in the card's corner, so a manager who already shared it can clear it.
  • Two songs out the same day: one card each, newest first.
  • No cover art yet: an initials tile, never a gradient placeholder (house rule).
  • "Make smart link" opens the UPC field on the song's Distribute page, since the link can't be made without a code.

# Home reads dates as calendar days; the Paystack signature check never throws (2026-10-09, v1.92.13, no flag)

> Moved out of CLAUDE.md on 2026-10-22 (verbatim). "This file", "above", "below" and "the X section" in here refer to the old single CLAUDE.md: find the named section in docs/notes/README.md.

Two small correctness fixes found by reading the code for behaviour that only shows up outside Lagos or under hostile input. No flag, no schema change.

- **A release date is a calendar day, not an instant.** `releases.release_date` comes back as `"YYYY-MM-DD"`. `new Date("2026-11-24")` is UTC midnight, which is the evening of the 23rd anywhere west of UTC, so Home's `daysUntilDate` and `computeWeekProgress` were a day early in the Americas. `parseCalendarDayOrInstant` (`lib/home/state.ts`) reads a bare calendar day as local midnight (`${value}T00:00:00`, the same rule as `parseReleaseDate` in `lib/recap-copy.ts`) and leaves a full timestamp alone. Both callers use it. Tests switch `process.env.TZ` at runtime (New York, Los Angeles, Lagos, Tokyo) and restore it in `finally`; two deliberate breaks (a plain `new Date(value)` in each function) were each caught.
- **The webhook signature check moved to `lib/paystack-signature.ts` and compares decoded byte lengths.** The old inline version compared the length of two hex STRINGS, then built buffers; a forged signature of the right length that is not hex decodes to a short buffer and `crypto.timingSafeEqual` throws a RangeError, so the money webhook answered 500 instead of 401 (Paystack retries a 500). The helper returns false for anything that is not the full digest, re-encodes to refuse trailing junk, accepts upper-case hex, and never throws. `lib/paystack-signature-guard.test.ts` holds the route to the shared helper (no `createHmac` or `timingSafeEqual` in the route), the byte-length compare and `timingSafeEqual`; three deliberate breaks (hex-length compare, dropping the re-encode, `equals` instead of `timingSafeEqual`) were each caught.
- **Verified:** full suite 7,696 passing, `tsc` clean, eslint clean on every touched file, `next build` green with `/auth`, `/dashboard`, `/onboarding`, `/settings`, `/locked` still static. **Not verified:** nothing seen with a real session; no real Paystack delivery was sent (the signature helper is covered by unit tests only).

# Homepage UrgAns demo loop (2026-11-01, #956, part of #951)

"Watch the demo" in the homepage hero now opens its overlay on a short in-page loop of UrgAns, built with the Stageshow kit (`docs/notes/2026-11-01-stageshow-kit.md`): a manager asks what is still open on Golden Hour, UrgAns answers and offers to give the playlist pitch to Ife, the manager taps Assign. About 15 seconds, then New chat clears the thread. Northline Music demo team, fictional artists. The YouTube video is one tap away under the loop ("Watch the full video") and its iframe still mounts only on that tap.

**Differs from the mock (decided 1 Nov in the build session, relayed for Oyin):** the mock put the loop in the hero in place of the link. Since #952 the hero already plays its own loop right under the link, so two loops would compete on one screen and a 440px frame there would push the proof line down. The link stays; the loop plays in the overlay.

## Files

- `apps/homepage/app/components/landing/demo-loop/DemoLoopScene.tsx`: the stage and script, from the approved mock. Loaded only by `DemoLoop.tsx`.
- `demo-loop.css`: the scene's styles, `--ud-*` tokens with a dark set under `html[data-marketing-theme="dark"]`, unlayered so they beat the kit's theme values.
- `DemoLoop.tsx`: the host, the hero loop's pattern (`HeroLoop.tsx`) and its cross-fade CSS (`.hero-loop*` in `globals.css`). Poster first; the scene is imported after mount and only without reduced motion.
- `poster.ts` and `apps/homepage/public/images/demo-loop/*.webp`: the four stills (desktop 720x440 at 2.5x, phone 358x580 at 3x, light and dark), the scene's own `POSTER` state.
- `WatchDemo.tsx` imports `DemoLoop` with `next/dynamic`, so the hero's first load carries none of it until the link is tapped.

## Traps

- **Small tweak from the mock:** the window sits 12px higher and the thread is a little tighter, so the question bubble is not clipped under New chat in the final frame.
- **Retake the stills whenever the scene or its CSS changes.** Same recipe as `docs/notes/2026-11-01-hero-loop.md` ("Retaking the stills"): a throwaway client page rendering `<DemoLoopScene theme compact />` in a fixed box 720px wide (358px for the phone), headless Chrome with `--force-prefers-reduced-motion` (the stage then shows `POSTER`), desktop `--window-size=720,440 --force-device-scale-factor=2.5`, phone `--window-size=358,580 --force-device-scale-factor=3`, then sharp to WebP.
- `demo_full_video_open` (GA and PostHog) counts taps on "Watch the full video"; `demo_video_open` still counts opens of the overlay.

# UrgAns on GPT-6.1 Sol, dictation on gpt-transcribe (2026-10-11, v1.110.0, founder)

> Moved out of CLAUDE.md on 2026-10-22 (verbatim). "This file", "above", "below" and "the X section" in here refer to the old single CLAUDE.md: find the named section in docs/notes/README.md.

Founder decision: plans and heavy chat on the GPT-6 **Sol** tier, not Astra. `lib/ai/model-ladder.ts`: pro `gpt-6.1-sol → gpt-6-sol → gpt-5`, max `gpt-6.1-sol (medium effort) → gpt-5.5 → gpt-5.2`, standard unchanged, quick stays `gpt-4o-mini` (gpt-6-luna is cheaper on paper but was not evaluated). `RODIUM_PLANNER_MODEL = 'openai/gpt-6.1-sol'` (`AI_PLANNER_MODEL` still overrides; check it is not set in Vercel or it pins the old model). Because pro and max share a primary and the router never re-tries a model, a max turn that times out drops to pro's sibling `gpt-6-sol`, and a pro turn that escalates lands on `gpt-5.5`. `supportsReasoningEffort` now includes `gpt-6`, so GPT-6 gets `max_completion_tokens` and its effort on the planner's structured call; **`effortForTools` sends GPT-6 no effort at all on a request with tools** (the safe path), because on the day this shipped every GPT-6 model answered `502 provider_unavailable` on RodiumAi and the tool + effort combination could not be measured (the 5.6 family rejects any effort but `none` with tools; GPT-6's catalogue lists `low..max`, so `none` may itself be rejected). Re-run `ROUTER_EVAL=1 … model-eval.integration.test.ts` once GPT-6 answers and relax it if it passes. `lib/credits/model-prices.ts` prices gpt-6.1-sol, gpt-6-sol and gpt-6-luna from the catalogue (Astra deliberately unpriced: it would become the dearest row and raise what an unknown model is charged), plus a separate `AUDIO_MODEL_PRICES` table (gpt-transcribe, gpt-live-transcribe, gpt-4o-mini-tts, gpt-realtime-2.1-mini, gpt-realtime-2.1) that nothing charges from. The speech model ids live in a fifth model-id file, `lib/ai/audio-models.ts` (the router guard lists it). Dictation (`/api/urgans/transcribe`) defaults to `openai/gpt-transcribe` when `URGANS_TRANSCRIBE_MODEL` is unset, so it needs only `CHAPPI_API_KEY`; each `urgans_voice_transcription` billing event now carries `{ model, bytes, mime, seconds }` (seconds from the provider's `usage.seconds`, null when absent). Dictation stays free with the 100/day cap. Note: the catalogue's prices for the older models have drifted about 1% above this table since 2026-10-01; not touched here.

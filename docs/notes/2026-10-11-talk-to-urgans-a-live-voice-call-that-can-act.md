# Talk to UrgAns: a live voice call that can act (2026-10-11, flag-off, founder)

> Moved out of CLAUDE.md on 2026-10-22 (verbatim). "This file", "above", "below" and "the X section" in here refer to the old single CLAUDE.md: find the named section in docs/notes/README.md.

Founder decisions: voice can take actions, not just talk; billed in credits per started minute. Everything sits behind `NEXT_PUBLIC_FEATURE_URGANS_REALTIME` (default off; needs `NEXT_PUBLIC_FEATURE_CHAPPI` and credits on): the Talk button (waveform, beside the composer mic and on HomeAskBar; the mic is relabelled "Dictate" when Talk is on) is hidden and all six `/api/urgans/voice/*` routes 404. **No changelog entry or version bump yet: the ledger entry lands at the flag flip (the EPK precedent).**

- **Rules** (`lib/urgans-voice-realtime.ts`, pure, client-safe): `VOICE_CREDITS_PER_MINUTE = 2` is THE rate; 30 min a call, 120 min per team per rolling 24h; started minutes from the SERVER's `started_at` (`decideTick`), so a tick sent twice charges once and a browser that stops ticking is still billed on its next tool/hear/speak/end call. On an out-of-credits or daily-cap refusal the just-started minute is forgiven; earlier unbilled minutes are not. One delegate tool, `urgans_do(request, confirmed?, cancel?)`; the voice model never sees UrgAns's 115 tools.
- **Server** (`lib/urgans-voice-realtime-server.ts`): config, minting a realtime client secret (`POST {base}/realtime/client_secrets`, session configured server side: instructions, the one tool, `gpt-live-transcribe` captions, `server_vad` with interrupt), cascade STT/TTS, and the `voice_sessions` reads/writes. Minutes are charged by `settleVoiceMinutes` in `lib/credits/credits-server.ts` (a `settleTurn` with request id `voice:<call>:m<n>`, metadata `reason: 'voice_minute'`); the credits history folds one call into one line, "Voice call with UrgAns". `credits-guard.test.ts` pins the one caller.
- **Acting** (`app/api/urgans/voice/tool`): calls `POST` from `app/api/urgans/route.ts` IN-PROCESS with the caller's own `authorization`/`cookie`, so a voice request runs the same ladder, tools, guards, confirmation gate and per-turn credits as typing; `x-urgans-surface: voice` only relabels its `ai_usage_events.feature` as `voice`. **The confirmation gate survives voice:** a proposed gated action is stored on `voice_sessions.pending_action`; a spoken or tapped yes replays exactly that stored action (cleared before it runs), never arguments from the model or the browser. Silence for 15s cancels. `lib/urgans-voice-realtime-guard.test.ts` holds all of this structurally; `app/api/urgans/voice/tool/route.test.ts` drives it.
- **Transports** (`components/chappi/voice/transports.ts`): `cascade` (DEFAULT: browser pause detection → `/voice/hear` gpt-transcribe → `/voice/tool` → `/voice/speak` gpt-4o-mini-tts, all on RodiumAi, ~2-4s a reply, stops talking when interrupted) and `realtime` (WebRTC to `{base}/realtime/calls` with the ephemeral secret, data channel `oai-events`, barge-in, one reconnect via `session` with `resumeSessionId`). Chosen by `URGANS_VOICE_TRANSPORT`; realtime falls back to cascade when no realtime upstream is configured. **Verified 2026-10-11:** RodiumAi serves `/v1/audio/speech` (gpt-4o-mini-tts, voices alloy and marin) and `/v1/audio/transcriptions` (gpt-transcribe, `usage.seconds`), but has NO realtime session endpoint (`/v1/realtime/client_secrets`, `/sessions`, `/calls`, `/transcription_sessions` all 404; a websocket upgrade to `/v1/realtime` got 403 through the sandbox proxy and is unverified). So realtime needs `OPENAI_REALTIME_API_KEY` (direct to api.openai.com, bare model ids) or `URGANS_VOICE_REALTIME_BASE`. Neither transport has been run in a browser.
- **UI**: one `VoiceSheetHost` mounted by AppShell (store `useVoiceCallStore`) so a call survives the composer re-rendering and page moves; `VoiceSheet` (docked lower half on desktop, full screen on mobile; primer on first use, mic-denied help per browser, connecting, listening, thinking, speaking, acting, confirming, reconnecting, out of credits with Buy credits, error with Type instead, summary), `VoiceOrb` (static level bar under reduced motion), `VoiceConfirmCard`, live captions (last two lines, toggle to full transcript), Mute / End / Captions, Space mutes, Esc ends, meter "2 credits/min · 1:42 · 46 left" amber with a spoken heads-up a minute before the end. Every finished line is appended to `useChappiStore`, so the call lands in the chat history. Analytics: `urgans_voice_call_started|ended|failed` (no audio, no text).
- **Cost** (estimate, `voiceMinuteCostRodi` in `lib/credits/pricing.ts`): a busy realtime-2.1-mini minute ≈ 3.4 RODI (≈1.4 credits at 3x), ≈4.7 RODI (≈1.9 credits) with live captions; cascade minutes cost well under 1 RODI of speech but every utterance is a normal UrgAns turn, charged as typed. Reconcile weekly from `voice_sessions` token columns (browser-relayed, advisory).
- **Known gap**: on the realtime transport the browser holds the upstream connection, so a modified client that never calls tick/tool/end could talk (not act) for free up to the provider's session limit; acting always goes through the server and bills first. Cascade has no such gap.
- **Activation checklist**: (1) apply `supabase/migrations/20261011150000_voice_sessions.sql` to prod; (2) optionally set `URGANS_VOICE_TRANSPORT=realtime` + `OPENAI_REALTIME_API_KEY` (otherwise cascade on the existing `CHAPPI_API_KEY`); (3) set `NEXT_PUBLIC_FEATURE_URGANS_REALTIME=true` in Vercel Production and redeploy (inlined at build time); (4) test a call on our own team: plan, add a task, change a date with a confirmation, and check the ledger shows `voice_minute` rows plus the action charges; (5) changelog entry + minor bump at the flip.

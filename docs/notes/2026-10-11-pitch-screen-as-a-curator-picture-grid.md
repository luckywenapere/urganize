# Pitch screen as a curator picture grid (2026-10-11, v1.104.0, founder)

> Moved out of CLAUDE.md on 2026-10-22 (verbatim). "This file", "above", "below" and "the X section" in here refer to the old single CLAUDE.md: find the named section in docs/notes/README.md.

Founder brief: "images of the curators first in a grid like a menu", and cut text aggressively so a 5th grader is not overwhelmed, on desktop and mobile. `PitchComposer` (shared by the release's Pitch scene and /dashboard/pitching, so both changed together) now shows platform chips, then a square photo grid (2 / 3 / 4 columns), then, only once a curator is picked, a card with the song link, an optional note and Send. Cut from the screen: the genre box (the route still takes `?genre=`), field labels and helper lines, the song title field (shown only when the release has no title), the follower count, genre tags, the "x/y waiting" counter, and the "Sent ... by ..." line on sent rows. In the scene, curators come first and Sent shows only when there is something sent. `BrowsablePlaylist` gained `curatorPhotoUrl` (a signed URL from `loadCuratorPhotoUrls`; the storage path never leaves the server); a curator with no photo gets a deterministic gradient tile with initials.
